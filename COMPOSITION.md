# Composition

Composition defines how visual elements are arranged and how the viewer's attention moves through the thumbnail.

## Core Principle

Build around one dominant visual idea.

Everything else should support, contrast with, contextualize, or amplify it.

Do not confuse visual simplicity with a low number of objects. A complex image can function as one perceptual object if it reads as a coherent unit.

## Perceptual Hierarchy

Before finalizing the composition, determine:

1. What is seen first?
2. What is seen second?
3. What is discovered afterward?

The dominant element should be immediately apparent at thumbnail size.

Secondary elements must not accidentally compete with it.

## Visual Density

Choose density according to the concept.

Sparse compositions are appropriate when a single object or idea carries the thumbnail.

Denser compositions are appropriate when multiple elements are necessary to communicate the concept.

When using many elements, organize them into clear groups and establish hierarchy rather than simply filling available space.

## Negative Space

Use empty space deliberately.

Negative space can:

- isolate a subject
- increase emphasis
- improve readability
- create tension
- provide room for typography
- make a dense composition easier to understand

Do not fill empty space merely because it exists.

## Scale & Position

Use scale and positioning to establish importance.

Large elements generally command attention. Smaller elements can provide context or contrast.

Position elements according to the intended visual flow rather than defaulting to rigid templates such as the rule of thirds.

## Balance

The composition should feel intentional and stable unless imbalance is itself useful to the concept.

Avoid accidental tangencies, awkward overlaps, distracting edges, and elements that appear to have been placed without regard to the rest of the frame.

## Thumbnail-Size Test

The composition must remain understandable when viewed small.

If reducing the thumbnail causes the hierarchy to collapse, simplify, enlarge, reposition, or remove the relevant element.

## Final Rule

Do not optimize for the maximum amount of visual information.

Optimize for the maximum amount of useful information that can be perceived quickly.
